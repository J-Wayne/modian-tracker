# modian-tracker

摩点众筹项目金额监测小工具：定时抓取项目当前筹款金额，存进 CSV，并自动绘制金额变化曲线。

## 功能

- 定时抓取指定摩点项目页的当前筹款金额
- 追加写入 CSV，不覆盖历史数据，支持中断后继续
- 每次抓取后自动更新金额变化曲线图

## 安装

```bash
pip install -r requirements.txt
playwright install chromium
```

## 运行

```bash
python modian_tracker.py
```

在脚本顶部可修改：

| 变量 | 说明 | 默认值 |
| --- | --- | --- |
| `URL` | 要监测的项目页地址 | 摩点 160465 |
| `INTERVAL` | 采样间隔（秒） | 60 |

按 `Ctrl + C` 停止。

## 输出

运行后生成 `data/` 目录：

- `history.csv`：时间与对应金额
- `curve.png`：金额变化曲线

## 说明

- 金额取自页面中数值最大的 `¥` 金额，适用于大多数项目页；若曲线出现明显跳变，可根据实际页面结构收紧提取规则。
- 请合理设置采样间隔，避免对目标站点造成压力。
- 本项目仅用于个人数据记录。
